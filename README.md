# FutureAnalysis

期货多空逻辑分析报告仓库。

## 数据来源
- 盘面与基本面客观数据：奇货可查（https://x.qhkch.com/，需用户登录）
- 策略逻辑：本地「期货多空逻辑」14 个 Skill（基差安全边际 / 商品价值投资 / 驱动信号验证 / 产业链利润 / 跨品种套利 / 跨期套利 / 库存+基差+利润 / 库存周期趋势 / 事前风控 / 概率赔率 / 虚实盘比 / 反转信号 / 期限结构 / 估值驱动矩阵）

## 目录结构
```
reports/
  <品种><合约>_<日期>/
    <report>.html      # 自包含的分析报告（内联 CSS，无外部依赖）
    data/              # 支撑报告的客观原始数据（奇货可查 ECharts 导出 JSON，可复核）
```

## 流程说明
1. 用户提供期货合约（如 纯碱 2609）
2. 学习该商品产业链，规划 S4/S5 所需关联品种采集清单
3. 经 browser-skill 连接已登录的奇货可查，校验登录态并采集客观数据
4. 客观数据逐一匹配 14 个 Skill，仅完全满足触发条件才生成策略（宁缺毋滥）
5. 生成 HTML 报告并推送至本仓库

所有报告均为客观数据驱动，已屏蔽研报 / 机构观点 / 新闻等主观文本。
